# Adopter templates

Copy these into the **project** that will use the skills. This skills repo does not keep a product backlog of its own.

| File | Copy to |
|------|---------|
| `010-backlog-ideas.mdc` | `.cursor/rules/010-backlog-ideas.mdc` |
| `backlog-README.md` | `docs/backlog/README.md` |
| `card-template.md` | reference only (the `/backlog` skill already embeds it) |
| `pulse-hotspots.md` | `docs/pulse-hotspots.md` (optional) |

Also create empty folders:

```text
docs/backlog/open/
docs/backlog/done/
docs/research/
```

Canon is whatever design source of truth the project already has (`GDD.md`, `SPEC.md`, `docs/canon.md`, …). Point the **Canon** field on cards at it. Do not invent a canon doc just to adopt these skills.
